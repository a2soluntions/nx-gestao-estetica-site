2. Precisa de internet para o sistema funcionar?

Não! O sistema roda 100% no seu computador (offline). Sua clínica nunca para de trabalhar mesmo que a internet oscile ou caia. A internet só é usada quando você clica para abrir o WhatsApp Web.

3. Posso usar em mais de um computador na mesma clínica?

Sim! O sistema possui compatibilidade nativa com Rede Local (LAN), permitindo que a recepcionista e os profissionais usem a mesma base de dados. Caso deseje licenças extras para mais computadores, temos condições especiais facilitadas.
